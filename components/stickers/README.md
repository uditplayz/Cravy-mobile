# components/stickers

Die-cut vinyl sticker components and FSSAI food markers.

Planned:

- `VinylSticker` - rounded sticker with thick white die-cut edge, ink outline, slight rotation, hard offset shadow. Built with `react-native-svg`.
- `DietMarker` - FSSAI-style veg (green square + green dot), non-veg (red/brown square + triangle), egg (yellow square + dot) markers. These replace any text or emoji indicators.

Nothing is implemented until a reference PNG exists in `design-references/`.
